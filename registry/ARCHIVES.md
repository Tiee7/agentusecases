# 案例正文档案

当前范围以[覆盖记录](source-case/coverage.json)为准：本分支1,381条已取得的案例正文入Git；19条有完整中文译文，1,362条待翻译；30条历史事实整理保留在结构化数据中，不再作为案例正文展示。商业深研36篇；本轮新增深研1篇、完整译文1篇、简报0篇。其他独立分支合并后需重新计算总数。

`archives/<id>.json` 保存源 URL、观测时间、正文与字段 SHA-256、原文 `source_text`，以及按原文哈希关联的 `translation` 和 `editorial`。原文是当时已取得的页面正文提取文本，包含简介、方法、结果、限制、试用模板和原有链接；不是整页 HTML，也不包括外链文章全文。缺失字段不补造；Wanted 未取得不写成 0。

历史1,359条批次中，93条来自当批新取得的HTML、1,266条来自历史正文缓存；最新独立爬虫快照为2026-10-17，覆盖1,381条正文与详情，见[刷新元数据](refresh.json)。本次研究未重新请求源站，只为既有Telegram家庭待办案例归档增加完整中文翻译。现有1,381份正文可随Git恢复；原始HTML和工作数据库仍只在忽略的本地目录，本地缓存不能称为已入Git。

每日爬虫对取得的新正文生成公开档案并刷新覆盖记录；源站更新后保留译文的版本信息，页面明确提示待同步，不把旧译文当作当前翻译。中文翻译不由爬虫自动生成。失败保留之前成功的观测与错误状态。日常 artifact 只保存案例数据，不上传 HTML 缓存或工作区其他文件。
