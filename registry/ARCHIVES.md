# 案例正文档案

当前范围以[覆盖记录](source-case/coverage.json)为准：1,381 条已取得的案例正文入 Git；37 条有完整中文译文，1,344 条待翻译；30 条历史事实整理保留在结构化数据中，不再作为案例正文展示。商业深研为 43 篇；另有 [16 篇简要分析](../research/brief/INDEX.md)，独立统计。正文、译文、事实整理和商业研究是不同产物。

`archives/<id>.json` 保存源 URL、观测时间、正文与字段 SHA-256、原文 `source_text`，以及按原文哈希关联的 `translation` 和 `editorial`。原文是当时已取得的页面正文提取文本，包含简介、方法、结果、限制、试用模板和原有链接；不是整页 HTML，也不包括外链文章全文。缺失字段不补造；Wanted 未取得不写成 0。

当前 1,381 份正文均有 HTML 采集哈希凭据并已进入 Git，可随仓库恢复；原始 HTML、工作数据库仍只在忽略的本地目录，本地缓存没有永久保存保证，也不能称为已入 Git。

每日爬虫对取得的新正文生成公开档案并刷新覆盖记录；源站更新后保留译文的版本信息，页面明确提示待同步，不把旧译文当作当前翻译。中文翻译不由爬虫自动生成。失败保留之前成功的观测与错误状态。日常 artifact 只保存案例数据，不上传 HTML 缓存或工作区其他文件。

[本批七条](source-case/batch-02.json)来自既有分类顶部排序 24–30，不能解释成全站热度或 Wanted 排名。未读取外部链接文章、未启动新商业深研。首页仍没有“最近收录”，目录刷新不写 research/reports。
