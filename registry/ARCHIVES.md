# 源站案例档案

2026-10-16：目录 1,359 条，23 篇既有商业深研的阅读页开头提供详细原创双语整理（介绍、方法、结果、限制），独立 `/cases/<id>/` 页面同时展示源站模板、实际 Done with agent、推荐工具和字段凭据。其余 1,336 条已有字段档案和源站模板，公开详细叙述仍待整理；不能称为 1,359 篇完整正文转载。

本批普通公开访问取得 93 篇 HTML：23 篇已研究案例，以及本环境原先缺正文的 70 条；另外 1,266 条使用 2026-10-14 历史正文缓存。首页／站点地图发现 5 个新增条目，目录从 1,354 增至 1,359。本批不是全站详情刷新，没有启动新商业研究。

每个 `archives/<id>.json` 记录来源 URL、实际观测时间、HTML／正文 SHA-256、字段状态和字段哈希。历史提取正文没有 HTML，不能补造 HTML 哈希。原文已读但公开重述未整理、字段未取得、外部原作者无法读取是三个独立状态。目录实际 Done with 中 1,123 条有具名工具，236 条明确为自建或未命名 agent；不拿推荐试用工具补位。Wanted 当前全部未知，不填 0；未取得作者不以域名猜测。旧重述保留其版本哈希，源站变化后在页面标记过期。刷新失败保留上次成功观测并显示最近错误。

未找到允许全文再发布的明确许可。许可检查页面及哈希在 [archive-policy.json](archive-policy.json)，批次范围在 [archive-batch.json](archive-batch.json)。公开 Git 不包含本批原始长文或全文翻译；23 篇整理为自行组织的事实重述，结果标明源站声称而非独立验证。源站提供的功能性试用模板保留既有独立字段和归属，不冒充原作者实际提示词或本站自编模板。

完整原始快照仅在本环境忽略目录 `data/source-archive`；这是本地缓存，不承诺永久私有存储。新的日常 Actions artifact `usecase-history-public` 清除 observations.body 后 VACUUM，仅保留同步需要的公开字段、哈希、来源模板与实际 agent 元数据；不上传原始 HTML。本次没有重新获取被禁止的旧 artifact，也未重试受阻 Substack。首次切换后的日常任务若没有新版 artifact 将从公开来源正常开始，不读取旧 artifact。

目录爬虫仍只刷新 registry，不修改 research/reports；首页保持没有“最近收录”区域。外部原作者读取失败的具体原因独立显示，不再被泛化成源站案例未读。
