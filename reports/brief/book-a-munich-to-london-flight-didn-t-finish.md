## 完整中文译文

预订慕尼黑至伦敦机票（未完成）
用户让 AI Agent 预订从慕尼黑到伦敦的航班；Agent 搜索了航司网站，但无法完成预订。
使用工具
自建或未命名 Agent
他们做了什么
用户指示 AI Agent 预订 25 日从慕尼黑至伦敦的航班。Agent 在大约十秒内在 Google Flights 上找到了航班选项，随后尝试通过航司及在线旅游网站完成出票购买，但英国航空（British Airways）、汉莎航空（Lufthansa）、易捷航空（easyJet）、Kayak、Skyscanner 以及 Expedia 均对其进行了拦截或验证质询；Kiwi 的 MCP 服务器是唯一成功返回航班列表并提供交接链接以供用户手动完成乘客信息填写的途径。
进展与成效
Agent 在常规预订网站上始终未能到达填写乘客姓名详情的页面，因此未能完成机票预订。唯一成功的步骤是 Kiwi 的 MCP 服务器，它在四秒内返回了 15 个航班选项，并提供了一个供用户手动结账的链接。
值得注意
帖文指出不允许破解 CAPTCHA 验证码，也不允许伪装成真人，这似乎是阻止 Agent 最终完成预订的关键约束。
