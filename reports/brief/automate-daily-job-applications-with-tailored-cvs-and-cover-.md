## 完整中文译文

使用定制简历与求职信自动化每日求职申请
一个 n8n 流水线每日运行以搜索职位，利用 AI 定制简历与求职信，并通过电子邮件发送申请资料包。
使用工具
N8
n8n
他们做了什么
该 n8n 工作流按每日计划运行，通过 Jina AI 从 LinkedIn 和作品集等来源读取求职者个人资料，生成求职搜索关键词，从 API 获取职位列表，通过 Google 表格去重，并由 AI 对最佳匹配项进行排序。针对每个选定的职位，它会起草一份定制的求职信；在原作者的配置中，工作流还可以在 GitHub 中编辑 YAML 格式的简历，触发 GitHub Action 编译出 PDF，然后将申请资料包发送至邮箱；求职者人工审核收到的资料包，并通过职位链接手动提交申请。
进展与成效
作者表示该流水线端到端包含约 51 个节点，但并未实现全自动投递：实际上邮件是发送给作者本人，然后由作者手动申请，因为在没有 API 的情况下自动化招聘门户投递被描述为几乎不可能。文中未提供任何面试或录用结果。
值得注意
作者称使用其自制的 n8n-as-code 辅助工具大约花了两个小时完成构建，且编辑简历的 GitHub 子流程是可选的，如果仅附加静态 PDF 则可以将其移除。

### 业务、交付与替代方案
可交付的是材料准备与筛选辅助，不能销售为已验证的全自动门户投递或提高录用率。应先比较招聘网站提醒、静态简历与人工筛选；任何改写须忠于真实经历。对外代运行还要核实平台许可、资料权限和服务条款，不能由“开源/可自托管”推出任意托管转售都获许可。

### 自用净收益与证据边界
求职期可能存在周期任务，但普通人的实际每周职位量、复核返工和维护未知。若设初始 S、每周毛省 G、复核维护 M、新增周现金 C，则连续回本周数仅在分母为正时为 25S/[25(G−M)−C]。删掉旧稿十至十二周及一至两个月通常为负的断言，没有从假设反推实测。
